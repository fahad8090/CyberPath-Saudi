# CyberPath-Saudi

🇸🇦 Cyber Path - مستشارك السيبراني السعودي

"نحو جيل سيبراني متمكن يحمي مقدرات الوطن"

مستشارك السيبراني هي أداة تحليلية تفاعلية تم تطويرها لتكون المرجع الأول للمواهب الوطنية في تحديد مساراتهم المهنية داخل قطاع الأمن السيبراني السعودي.

🚀 لماذا هذا المشروع ؟

في ظل التحول الرقمي المتسارع في المملكة، برزت الحاجة لتوجيه الكوادر البشرية نحو التخصصات الدقيقة.
هذا المشروع يردم الفجوة بين شغف المبتدئين ومتطلبات سوق العمل الفعلية.

🛠 المميزات الرئيسية:

توطين المهارات: مصمم خصيصاً للمواطن الطموح ليتوافق مع احتياجات المنشآت السعودية.


المطابقة مع ضوابط NCA: الأسئلة والمسارات مبنية لتتوافق مع إطار المهارات المعتمد من الهيئة الوطنية للأمن السيبراني.


دعم القرار المهني: إنهاء حيرة البدايات عبر تقديم خارطة طريق واضحة لكل تخصص (دفاعي، هجومي، حوكمة).


تحديثات 2026: محتوى محدث يواكب أحدث الشهادات المهنية المطلوبة مثل (GCIH, CCSP, CISM).

فهد متعب السبيعي
مبتكر حلول تقنية مهتم ببناء القدرات البشرية في مجال الأمن السيبراني.

هذا المشروع متاح كمبادرة مفتوحة المصدر، وأرحب بالتعاون مع الجهات الحكومية والخاصة لتطويره وتوسيع نطاقه لخدمة أكبر عدد من شباب وبنات الوطن.
