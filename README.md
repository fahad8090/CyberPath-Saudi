# 🇸🇦 Cyber Path | مستشارك السيبراني السعودي

> **"نحو جيل سيبراني متمكن يحمي مقدرات الوطن"**
> مرجع تقني وتفاعلي متكامل لتوجيه المواهب الوطنية نحو التخصصات المهنية الدقيقة في الأمن السيبراني.

---

## 🚀 نظرة عامة (Project Overview)
في ظل التحول الرقمي المتسارع الذي تشهده المملكة العربية السعودية، تبرز الحاجة الماسة لسد الفجوة بين الشغف الشخصي ومتطلبات سوق العمل الفعلية. **Cyber Path** هو مشروع (Frontend) تفاعلي يهدف إلى إنهاء "حيرة البدايات" للمبتدئين عبر تقديم تحليل دقيق للمسارات المهنية.

## 🛠 المميزات الرئيسية (Key Features)
* **توطين المعايير:** محتوى مصمم خصيصاً ليتوافق مع احتياجات المنشآت والجهات السعودية.
* **المطابقة مع ضوابط NCA:** الأسئلة والمسارات مبنية لتتوافق مع إطار المهارات المعتمد من **الهيئة الوطنية للأمن السيبراني**.
* **خارطة طريق ذكية:** تقديم مسار تعليمي متسلسل يشمل التخصصات الثلاثة الكبرى (دفاعي، هجومي، وحوكمة GRC).
* **تحديثات 2026:** مواكبة أحدث الشهادات العالمية المطلوبة محلياً مثل (GCIH, CCSP, CISM, OSCP).
* **تجربة مستخدم سيبرانية:** واجهة عصرية (Cyber-Dark Theme) توفر تجربة تصفح تفاعلية وسريعة.

## 💻 التقنيات المستخدمة (Tech Stack)
* **Frontend:** HTML5 & CSS3 بتقنيات التصميم الحديثة (Responsive Grid & Flexbox).
* **Logic:** JavaScript (Vanilla JS) لإجراء عمليات الفرز والتحليل اللحظي لمدخلات المستخدم.
* **Animation:** CSS Cyber-Grid Animation لتعزيز الهوية البصرية التقنية.
* **Documentation:** ميزة التصدير لتمكين المستخدم من الاحتفاظ بخطته المهنية.
